# Raw claude port of primewatch to rust

This is a raw, unmodified, almost 100% automated conversion of Prime Watch to Rust.

The actual version (in the 'rust-conversion' and/or 'main' branch) will have/has had plenty of adjustment by a human (Pwootage) prior to any sort of release.

But I wanted to upload this version, as-is, which does seem to function, before I did that. Triggers flash, the controls are a bit weird, but all the features seem to have been successfully ported over.
