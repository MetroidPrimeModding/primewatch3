       `*` prefix. Branches on `inst.type_name`:

       - `f32` → `{:0.8f}` if `exact` else `{:0.3f}`; `f64` → `{:0.16f}` / `{:0.3f}`.

       `false`) **here at the render callsite** — this is the P3.1/P4.2 "defaulting deferred to P7"
       contract. Rust `{:x}`/`{:#x}` for the `{:#x}` spec; `{:.3}` for floats (Rust has no `f` suffix).

  ### Watch for
  - **`GameInstance::pointer` is a Phase-4 type change** — keep `new` / `with_bitfield` behavior
    identical (field defaults `false`); only `with_member` populates it. `globals.rs` and
    `game_object_utils.rs` must still compile untouched.
  - Defaulting: reads are `Option` (P4.2). The inspector is the callsite that finally applies the
    C++ total-read default — `.unwrap_or(0)` / `.unwrap_or_default()` — **not** the read layer.
    Keep "unreadable" visually indistinguishable from "zero" only where C++ already was (it always
    was — `getRealPtr` clamps to 0).
  - egui 0.36 API: `CollapsingHeader::id_salt` (not the old `id_source`), `ctx.copy_text`,
    `Response::on_hover_text`, `ui.data_mut` for the per-vector index. Verify against the pinned
    `egui 0.36.1`, don't guess from a newer docs page.
  - `rstl::vector` monomorphized structs expose `first` (pointer→elem 0), `end` (live count),
    `size` (capacity). `inst.member(ctx, "first")` panics if absent — that's the intended
    C++ `operator[]` parity, fine for a well-formed `.bs`.
  - Number formatting: Rust `format!("{v:#x}")` yields `0x1a` (C++ `{:#x}` matches); `{:#b}` →
    `0b...` (matches). Floats: C++ `{:0.3f}` → Rust `{v:.3}`. Don't emit the C++ `f`-suffix quirk.
  - Recursion depth: the schema is a DAG but deeply nested (`CStateManager` → world → areas → …).
    No cycle guard in C++; don't add one, but the `ARRAY_CAP` / index-based vector view keep the
    per-frame node count bounded like C++.
  - This module has **no call site yet** (Phase 9 wires it into watch windows). Expect a dead-code
    warning on `Inspector` / `render`; do not add a speculative `app.rs` call. Do not `#[allow]` it
    unless clippy `--all-targets` fails the build — match how P6.2 left `get_areas` bare.
