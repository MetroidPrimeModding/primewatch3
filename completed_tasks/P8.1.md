  **`pub fn load_mesh(ctx: &Ctx, area: &GameInstance) -> Option<CollisionMesh>`**
  — ports `WorldRenderer::loadMesh` (`src/world/WorldRenderer.cpp:170-246`).
  Behavioral spec:
  1. `postConstructed = area.get_member(ctx, "postConstructed")?` (auto-derefs `*CPostConstructed`).
  2. `collision = postConstructed.get_member(ctx,"collision")?.get_member(ctx,"value")?`
     — `collision` (`rstl::autoptr<CAreaOctTree>` inline) then `["value"]` (auto-derefs `*CAreaOctTree`).
     C++ `if (collision.offset == 0) return {};` → `if collision.address == 0 { return None; }`.
  3. Read `matCount / edgeCount / polyCount / vertCount` = `collision.get_member(ctx,"<name>")?.read_u32(ctx)?`
     (`CAreaOctTree` member names: `matCount 0x24`, `edgeCount 0x38`, `polyCount 0x40`, `vertCount 0x48`).
     C++ sanity gate: `if any > 50000 { return None; }` (C++ prints "Bad read for polys").
  4. Array base addresses = `.address` of the (auto-deref'd, so already the pointee) members:
     `materials` (`*u32` 0x28), `edges` (`*CCollisionEdge` 0x3C), `polyEdges` (`*u16` 0x44),
     `verts` (`*f32` 0x4C), `edgeMats` (`*u8` 0x30), `polyMats` (`*u8` 0x34).
     **Preserve the C++ quirk verbatim:** `vert_material_start = collision["polyEdges"].address`
     (C++ line 191 reads vert materials from the *polyEdges* pointer, not `vertMats` — apparent bug;
     keep it, add a `// NOTE:` — `raw_vert_materials` is unused by `build_vertices` anyway).
  5. Fill the raw vecs (C++ lines 195-238) with `ctx.mem` reads at raw game addresses — **pass the
     address straight through, `GameMemory` masks `& 0x7FFFFFFF` internally, do not re-mask, do not
     byte-swap**:
     - `materials[i]` = `ECollisionMaterial(mem.read_u32(mat_start + i*4).unwrap_or(0))`
     - `raw_verts[i]` = `Vec3::new(read_f32(vert_start + (i*3+k)*4).unwrap_or(0.0) for k in 0..3)`
     - `raw_vert_materials[i]` = `read_u8(vert_material_start + i).unwrap_or(0) as u16`
     - `raw_edges[i]` = `[read_u16(edge_start + (i*4)+0), read_u16(edge_start + (i*4)+2)]` (each `.unwrap_or(0)`)
     - `raw_edge_materials[i]` = `read_u8(edge_material_start + i).unwrap_or(0) as u16`
     - `raw_polys[i]` = `[read_u16(poly_start + (i*6)+0/+2/+4)]` (each `.unwrap_or(0)`)
     - `raw_poly_materials[i]` = `read_u8(poly_material_start + i).unwrap_or(0) as u16`
     (C++ reads are total / OOB→0; `.unwrap_or(0)` matches that — a valid snapshot never misses.
     Only the *structural* misses in steps 1-3 bail to `None`, via `?`.)
  6. `res.min` / `res.max` = a local `read_cvector3f(ctx, &m)` helper (mini-port of
     `MathUtils::readAsCVector3f`, `src/utils/MathUtils.cpp:4-10`: `Vec3::new(m.member(ctx,"x")
     .read_f32(ctx).unwrap_or(0.0), …y, …z)`), applied to `area.member(ctx,"aabb").member(ctx,"min")`
     / `"max"` (`CGameArea.aabb` is `CAABB` at 0x6C → `CVector3f min/max`).
  7. `res.build_vertices()`, then `Some(res)`.

  **`impl CollisionMesh { pub fn build_vertices(&mut self) }`**
  — ports `CollisionMesh::initGlMesh` (`src/world/CollisionMesh.cpp:5-87`) exactly, except it fills
  `self.verts: Vec<Vert>` instead of constructing an `OpenGLMesh`. Per-poly:
  - `poly_flags = self.materials.get(self.raw_poly_materials[i] as usize).copied().unwrap_or(ECollisionMaterial(0))`
    — **deviation:** C++ `materials[...]` / `raw_edges[...]` / `raw_verts[...]` are all unchecked
    `std::vector::operator[]`; use `.get(..).copied().unwrap_or_default()` everywhere an index comes
    from memory, so a bad index degrades instead of panicking (repo "OOB → skip, never panic"
    convention). Note it once.
  - the 3-edge → 3-index resolution (C++ lines 15-40): identical branch structure.
  - `FLIPPED_TRI` swap of `i1`/`i3` (lines 42-47) via `poly_flags.contains(ECollisionMaterial::FLIPPED_TRI)`.
  - `n = (v1 - v3).cross(v1 - v2).normalize()` (glam; degenerate tri → NaN, same as C++).
  - colour ladder (lines 55-64) **verbatim, including the dead `|| n.z > 0.85` on the wall/ceiling
    arms** — add a `// (C++ has a redundant `|| n.z > 0.85` on all three arms; preserved verbatim)`.
  - push 3 `Vert`s with barycentric `[1,0,0]`/`[0,1,0]`/`[0,0,1]`.
  Drop `CollisionMesh::draw()` — P8.2/P8.4.
