  1. **`WatchedEditorId` + UI state on `App`** (`src/app.rs`).

  2. **Port `ImGuiTextFilter`** as a small `ObjectFilter` (new `src/object_filter.rs`,
     `mod object_filter;` in `main.rs`; or a private module in `app.rs` — implementer's call,
     prefer its own file + unit tests).
     - `ObjectFilter { raw: String }` with `pub fn passes(&self, text: &str) -> bool` and an
       egui text-edit helper (or just expose `&mut raw` and let `app.rs` add the
       `ui.text_edit_singleline`).
     - Semantics of `ImGuiTextFilter::PassFilter` (imgui `imgui.cpp`): split `raw` on `','`,
       trim each term, drop empties. Term with leading `-` is a negative filter (match on the
       remainder). Empty filter (no terms) → always pass. Else: if any negative term is a
       substring of `text` → fail. If there are positive terms and none is a substring of
       `text` → fail. Otherwise pass. (Matching is case-sensitive substring, matching C++.)
     - Unit-test: empty passes all; `"foo"` include; `"-foo"` exclude; `"foo,-bar"` combo;
       whitespace trimmed.
  3. **`render_objects_window` in `app.rs`** — ports `drawObjectsWindow:502-668` as a method/free
     fn taking the egui `&Context`, `&Ctx`, `&HashMap<TUniqueID, GameInstance>` and `&mut`
     refs to the step-1 state (+ `&mut Vec<MenuAction>`-style deferral not needed — no memory
     mutation here, only local UI state, so mutate directly). One `egui::Window::new("Objects")`.
     Structure, in C++ order:
     - `ui.label(format!("Current object count: {}", objects.len()))`.
     - Build `vtables: BTreeMap<u32, (u32 active, u32 inactive)>` by iterating `objects`, reading
       `entity.member(ctx,"vtable").read_u32(ctx).unwrap_or(0)` and
       `entity.member(ctx,"active").read_bool(ctx).unwrap_or(false)` (C++ `drawObjectsWindow:508-519`).
       Also build `eid_to_entity: HashMap<u32, &GameInstance>` and reuse `objects` itself as the
       uid map (it is already keyed by `uniqueID`; C++ `uidToEntity` is the same content — but
       C++ keys on `entity["uniqueID"].read_u16()`, so build an explicit
       `uid_to_entity: HashMap<u16, &GameInstance>` keyed that way to match exactly).
     - For each vtable with `vtable_class_name(v).is_none() && (0x8000_0000..0x8070_0000).contains(&v)`
       → `unknown_vtables.insert(v)` (C++ `:527`).
     - `"Copy unknowns (N)"` button → `ui.ctx().copy_text` of the joined
       `format!("{{0x{v:08x}, \"\"}},\n")` lines (C++ `:533-539`).
     - `egui::CollapsingHeader::new("List of types")` → a 4-col grid/table
       (address / name / active / inactive). Address cell is a click-to-copy label copying
       `format!("{{0x{v:08x}, \"\"}},")` (C++ `:561-564`). name = `vtable_class_name(v)`.unwrap_or("unknown")`.
     - `ui.label("Editor ID: #38 Class: @CPlayer name: &name")` + the hint line (C++ `:585-586`),
       the filter text-edit, `ui.checkbox(&mut show_active_in_table_only, "Show active only")`.
     - Reset `table_hovered_uid = 0xFFFF` before the table (C++ `:590`).
     - Entities table, 5 cols (class / editorID / uniqueID / active / name), scroll area, ~400px.
       Iterate `objects` in a **stable order** — collect `(uid, &inst)` into a `Vec` and sort by
       `uid` (C++ iterates a `std::map<TUniqueID,...>`, i.e. uid-sorted; our `HashMap` is not).
       Per row: read `active` (skip if `show_active_in_table_only && !active`), `uid`, `eid`
       (`member(ctx,"editorID").read_u32`), `name` (`member(ctx,"name").read_string(ctx)` —
       `name` is `*u8`, auto-deref'd by `get_member`; `.unwrap_or_default()`).
       Build the filter probe string `format!("#{eid:08x}#{eid:08}@{type}&{name}", ...)` exactly
       as C++ `:613` and `continue` if `!object_filter.passes(&probe)`.
       Row: a full-width `ui.selectable_label(false, format!("{type}"))` (span all columns — use
       `ui.selectable_label` in the first cell or a full-width `Response`); on `.clicked()`
       upsert into `editor_ids_to_watch` (match on `eid`: update `last_known_uid` + `type_name`,
       else push new — C++ `:621-635`). On `.hovered()` set `table_hovered_uid = uid` (C++ `:637`).
       Remaining cells: `{eid:08x}`, `{uid:04x}`, `yes`/`no`, `name`.
     - `ui.label(format!("tableHoveredUid: {}", table_hovered_uid))` (C++ `:665`).
  4. **Per-object watch windows** — ports `drawObjectsWindow:671-704`. After the "Objects"
     window, loop `editor_ids_to_watch` with retain-style removal (collect indices to drop, or
     `Vec::retain` won't work because the body needs `&mut` + egui — use a
     `let mut i = 0; while i < len { ... if !open { remove(i) } else { i += 1 } }` or drain into
     a new Vec). Per entry:
     - `let mut open = true;` `egui::Window::new(title).open(&mut open).id(egui::Id::new(("watch", eid)))`
       with `.min_size([240.0, 200.0])`; title `format!("{type_name} {eid:08x}")` (C++ `:675`, the
       `##{eid}` is the id salt → use `.id(...)`).
     - Body resolution (C++ `:678-696`):
       1. If `uid_to_entity.get(&last_known_uid)` exists and its `editorID` == `eid` and its

       2. Else if `eid_to_entity.get(&eid)` exists → set `last_known_uid = entity uniqueID`,
          `inspector.render(..., false)`.
       3. Else `ui.label("Not loaded")`.
     - After the window, if `!open` remove the entry (C++ `erase`).
     - **Borrow note:** `eid_to_entity` / `uid_to_entity` borrow `objects` immutably; the watch
       loop mutates `editor_ids_to_watch` (`last_known_uid`) and reads `inspector` (`&self`).
       Keep the maps alive across the loop; don't hold a `&mut editor_ids_to_watch` element and
       the maps in a way that conflicts (index-based access sidesteps it).

  ### Watch for
  - **`Inspector::render` add_tree flag** — C++ `render(entity, false)` passes `addTree=false`;
    the "globals" window passes `true`. Match C++: `false` in watch windows.
  - **Stable table order.** C++ `entities` is a `std::map` (uid-sorted); our `HashMap` iteration
    is random → the table would shuffle every frame. Sort rows by `uid` before rendering.
  - **`name` is `*u8`.** `member(ctx,"name")` auto-derefs the pointer (P7.1: `get_member` sets
    `pointer` and derefs); `read_string(ctx)` then reads the C-string at the deref'd address.
    A null/OOB pointer → `read_string` returns `None` → `.unwrap_or_default()` = empty (C++
    `read_string` returns `""`).
  - **`unknown_vtables` persists across frames** (C++ `static`). It only ever grows — that is
    the intended behavior (a log of every unknown vtable seen this session). Use a field, not a
    local.
  - **Filter probe format string.** `#{:08x}#{:08}@{}&{}` — first `{:08x}` is hex eid, second
    `{:08}` is *decimal* eid zero-padded to 8 (C++ `fmt` default is decimal for an int). Keep
    both. The `#`/`@`/`&` sigils are literal (they let a user type `@CPlayer` to filter by class).
  - **egui has no "span all columns" selectable** like ImGui `ImGuiSelectableFlags_SpanAllColumns`.
    Approximate with a full-width `ui.selectable_label` in the first cell, or render the row as a
    single `ui.horizontal` with a `Response` union. Don't block on pixel-perfect table styling —
    behavior (click arms watch, hover highlights) is what matters.
  - **One-frame highlight lag** (step 5) — document as a sanctioned deviation, don't try to
    restructure the frame to eliminate it.
  - **Window close → erase** must not panic or skip an entry when multiple windows close in one
    frame. Index-based loop or drain-into-new-Vec.
  - Don't reintroduce the C++ demo-window / `mem_edit` — those are already handled (P9.1).
  - `.bs` offsets: don't hardcode — go through `member`.
